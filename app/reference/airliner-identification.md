How to tell common Airbus, Boeing, and Embraer airliners apart from the outside without any special tools or knowledge.  Start with the general type, then use the tables to narrow down to a model and variant.  Door and exit layouts can vary between airlines; when a clue is ambiguous, use several clues together.

## Quick Key

```
How many engines?
|
+-- 4 engines
|   +-- Two full-length decks of windows ..................... A380
|   +-- Hump only at the front of the fuselage ............... 747
|   +-- Single deck .......................................... A340
|
+-- 2 engines on the rear fuselage, T-tail ................... 717
|
+-- 2 engines under the wings
    +-- One aisle (narrow body), 2 main wheels on each side
    |   +-- Wheels exposed in flight, triangular fin at tail base . 737
    |   +-- Rounded nose, notched rear cockpit window ............. A320 family
    |   +-- 4 cockpit windows, long pointed nose, flat tail cone .. A220
    |   +-- Small and slim, 4 cockpit windows, pointed tail cone .. E-Jet
    |
    +-- One aisle, 4 wheels on each side, tall gear, long and thin  757
    |
    +-- Two aisles (wide body)
        +-- 6 wheels on each main gear
        |   +-- Blade-shaped flat tail cone, no winglets ........ 777
        |   +-- Black "mask" cockpit windows, curved winglets ... A350-1000
        +-- 4 wheels on each main gear
            +-- 4 cockpit windows, sawtooth engine rear, no winglets  787
            +-- Black "mask" cockpit windows, curved winglets ....... A350-900
            +-- Notched rear cockpit window, bulge under wing ....... A330
            +-- Like an A330 but with a smooth belly ................ A300, A310
            +-- Pointed nose, tail ends in a cone, shorter ......... 767
```

## Airbus vs Boeing

| Feature              | Airbus                                               | Boeing                                              |
|----------------------|------------------------------------------------------|-----------------------------------------------------|
| Nose                 | Rounder, blunter nose                                | More pointed nose (except the 777 and 747)          |
| Cockpit side windows | Rear-most side window has a notched top rear corner (A320, A330, A340) | Straight-edged windows, often V-shaped lower edge   |
| Wing strobes (night) | Double flash                                         | Single flash                                        |

## Boeing

| Model | Variant      | Length  | How to identify                                                                                       |
|-------|--------------|---------|-------------------------------------------------------------------------------------------------------|
| 717   |              | 124 ft  | Two engines on the sides of the rear fuselage; T-tail; larger with a rounder nose than regional jets with the same layout, such as the CRJ |
| 737   | All          |         | Narrow body; main wheels have no doors so they are visible in flight; triangular fin at the front base of the tail; engines hang low under the wing |
| 737   | Classic (-300, -400, -500) | 102-120 ft | Smaller wings, usually no winglets; small engines with flat-bottomed nacelles; now rare in passenger service |
| 737   | NG (-700, -800, -900) | 110-138 ft | Flat-bottomed oval nacelles with a straight rear edge; blunt tail cone; blended winglets, split scimitar winglets (pointed tips), or none |
| 737   | MAX (7, 8, 9, 10) | 117-144 ft | Round nacelles with a sawtooth rear edge; long pointed tail cone; split winglets with flat, square tips |
| 737   | -700 / MAX 7 | 110-117 ft | One overwing exit on each side                                                                   |
| 737   | -800 / MAX 8 | 130 ft  | Two overwing exits on each side; MAX 8-200 adds an extra exit behind the wing                         |
| 737   | -900ER / MAX 9 | 138 ft | Two overwing exits plus an extra exit or door plug between the wing and rear door, visible as uneven window spacing |
| 737   | MAX 10       | 144 ft  | Longest 737                                                                                           |
| 747   | All          |         | Four engines; hump at the front of the fuselage containing a partial upper deck                       |
| 747   | -100, -200   | 231 ft  | Short hump with few upper deck windows; no winglets                                                    |
| 747   | -400         | 231 ft  | Stretched hump; upright winglets (except the -400D)                                                   |
| 747   | -8           | 250 ft  | Even longer hump; no winglets, but long raked wingtips that continue the wing sweep; sawtooth engine nacelles; freighters keep a short hump |
| 757   | All          |         | Long, thin narrow body; tall landing gear with 4 wheels on each main gear; sloped "dolphin" nose        |
| 757   | -200         | 155 ft  | Usually two overwing exits, with no extra door between the wing and rear door                         |
| 757   | -300         | 179 ft  | Very long; extra door behind the wing with about a dozen windows between it and the rear door         |
| 767   | All          |         | Small wide body; pointed nose; 4 wheels on each main gear; tail ends in a cone                       |
| 767   | -200         | 159 ft  | Short and stubby for a wide body                                                                      |
| 767   | -300         | 180 ft  | Longer; many have tall blended winglets added                                                         |
| 767   | -400ER       | 201 ft  | Longest 767; raked wingtips without winglets; four doors on each side                                 |
| 777   | All          |         | Very large engines; 6 wheels on each main gear; blade-shaped flat tail cone; no winglets              |
| 777   | -200, -200ER | 209 ft  | Four doors on each side                                                                               |
| 777   | -200LR, -300ER | 209-242 ft | Longer raked wingtips and even larger engines                                                   |
| 777   | -300, -300ER | 242 ft  | Five doors on each side, including one directly over the wing                                         |
| 777   | 777X (-8, -9) | 233-252 ft | Folding wingtips with a visible hinge line near the end of each wing; -9 is the longest twin-engine airliner |
| 787   | All          |         | Four cockpit windows; smooth nose; long, thin wings that curve up in flight with no winglets; sawtooth engine nacelles; four doors on each side |
| 787   | -8           | 186 ft  | 10 or fewer windows between the first and second doors                                                |
| 787   | -9           | 206 ft  | 11-15 windows between the first and second doors                                                     |
| 787   | -10          | 224 ft  | More than 15 windows between the first and second doors                                               |

## Airbus

| Model | Variant      | Length  | How to identify                                                                                       |
|-------|--------------|---------|-------------------------------------------------------------------------------------------------------|
| A220  | All          |         | Doesn't look like other Airbus airliners; four cockpit windows; long, straight pointed nose; large engines for its size; canted winglets; flat tail cone |
| A220  | -100         | 115 ft  | About 12 windows between the front door and the overwing exit                                         |
| A220  | -300         | 127 ft  | About 17 windows between the front door and the overwing exit; looks noticeably stretched             |
| A300  |              | 177 ft  | Looks like a short A330 but with a smooth belly with no bulge; three doors on each side; now mostly freighters |
| A310  |              | 153 ft  | Shorter than the A300; two doors on each side; rare                                                   |
| A320 family | All    |         | Narrow body; rounded nose; notched rear cockpit window; no triangular fin at the base of the tail                |
| A320 family | ceo    |         | Smaller engines; small triangular wingtip fences or curved sharklets                                  |
| A320 family | neo    |         | Larger engines that sit closer to the ground and look more open at the rear; always has sharklets    |
| A318  |              | 103 ft  | Very short; tail fin looks oversized for the fuselage; rare                                           |
| A319  | ceo, neo     | 111 ft  | Short; usually one overwing exit on each side                                                         |
| A320  | ceo, neo     | 123 ft  | Two overwing exits on each side with no other exits between the front and rear doors                 |
| A321  | ceo, neo     | 146 ft  | Long; extra door ahead of and behind the wing (four doors on each side), or overwing exits in place of the doors on newer neos |
| A330  | All          |         | Two engines; notched rear cockpit window; bulge under the center of the fuselage between the wings; tall upturned winglets |
| A330  | -200, -800neo | 193 ft | Shorter                                                                                              |
| A330  | -300, -900neo | 209 ft | Longer                                                                                               |
| A330  | neo (-800, -900) |    | Larger engines; longer, more curved sharklet winglets                                                |
| A340  | All          |         | Four engines on a single deck; third main landing gear under the middle of the fuselage               |
| A340  | -200, -300   | 195-209 ft | Small engines that look undersized for the aircraft; looks like an A330 with four engines          |
| A340  | -500         | 223 ft  | Larger engines; four doors on each side; rare                                                         |
| A340  | -600         | 247 ft  | Very long and slender; larger engines; five doors on each side                                        |
| A350  | All          |         | Black "mask" around the cockpit windows; sleek nose; winglets that curve sharply upward                 |
| A350  | -900         | 219 ft  | 4 wheels on each main gear; about 15 windows between the first and second doors                       |
| A350  | -1000        | 243 ft  | 6 wheels on each main gear; over 20 windows between the first and second doors                        |
| A380  |              | 239 ft  | Four engines; two full-length decks of windows; very large wings                                      |

## Embraer

| Model | Variant      | Length  | How to identify                                                                                       |
|-------|--------------|---------|-------------------------------------------------------------------------------------------------------|
| E-Jet | All          |         | Small, slim narrow body with engines under the wings; four cockpit windows; short triangular fin at the base of the tail; pointed tail cone |
| E170  |              | 98 ft   | Shortest; no overwing exits; upright winglets                                                         |
| E175  |              | 104 ft  | No overwing exits; upright winglets, or larger winglets angled at 45 degrees on newer aircraft        |
| E190  |              | 119 ft  | One overwing exit on each side; upright winglets; 11 windows ahead of the overwing exit               |
| E195  |              | 126 ft  | Like the E190 but longer, with 12 windows ahead of the overwing exit                                  |
| E2    | E190-E2, E195-E2 | 119-136 ft | No winglets; much larger engines; the E195-E2 has two overwing exits on each side             |
